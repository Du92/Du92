### ⚛️ aXemg — Scientific computing framework

**Open-source Python package · Numerical software engineering**

A modular Python framework for numerical experiments in axion electrodynamics on fixed curved-spacetime backgrounds.

- Finite-difference simulation tools in 1D and 2D, with RK4 time integration.
- Configurable simulation setups, parameter sweeps, and scientific visualization.
- Organized Python package with examples, testing infrastructure, and reproducible workflows.

**Stack:** `Python` · `NumPy / Scientific Computing` · `pytest` · `YAML`

**[View source code →](https://github.com/Du92/aXemg)**
